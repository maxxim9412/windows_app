# Тексты для Google Play

## Название
QT

## Короткое описание (до 80 символов)
Отрывок дня, размышления, план чтения Библии и общение в малой группе.

## Полное описание

QT — приложение для тихого времени с Богом: читайте отрывок дня, записывайте
размышления, следуйте плану чтения Библии и оставайтесь на связи со своей малой
группой.

Возможности:

• Отрывок дня (QT). Каждый будний день — отрывок из Библии и четыре вопроса для
размышления: о чём отрывок, каким вы видите Бога, как применить, молитва.

• Ежедневное чтение Библии. План чтения на 6 дней в неделю с полным текстом
Синодального перевода прямо в приложении и отметками о прочтении.

• Напоминания. Мягкие уведомления в удобное время, чтобы не пропустить тихое
время.

• Малые группы («тройки»). Объединяйтесь с двумя людьми, делитесь
размышлениями, видьте, кто сделал заметку сегодня, и созванивайтесь голосом
прямо в приложении по расписанию.

• График церкви. Администратор церкви задаёт общий план отрывков и чтения — все
участники видят одно и то же.

Начните день со Слова Божьего вместе с QT.

## Заметки для формы Data safety (что указывать)
- Собираемые данные: адрес эл. почты, имя, пользовательский контент (заметки).
- Цель: работа приложения (аккаунт, обмен внутри группы).
- Передача шифруется.
- Пользователь может запросить удаление аккаунта.
- Реклама не показывается, данные не продаются.

## Разрешение микрофона (пояснение для Play)
Микрофон используется только для голосовых созвонов участников малой группы.
Аудио не записывается.
